# あなたの優しさの活かし方診断

星の学園リリス／乙女座 小さな力を育てる診断

６問の固定文章から、今の自分が活かしやすい優しさを見つける絵本の特典アプリです。星座を問わず利用できます。

## ファイル

- `index.html`：入口・質問・結果の画面
- `style.css`：生成り色・セージグリーン・若葉色のスマートフォン対応デザイン
- `diagnosis.js`：質問、結果文章、採点と同点判定
- `script.js`：回答、戻る、次へ、再診断の操作
- `assets/`：提供された５枚の画像（画像全体を表示）
- `tests/verify.cjs`：判定・画面・キーボードの確認用。実行環境にPlaywrightとEdgeが必要です。

`index.html`をブラウザーで開くだけで使えます。ライブラリ・API・外部フォントは不要です。回答は画面を開いている間だけメモリに保持し、サーバー送信・ブラウザー保存を行いません。

## 判定

各回答に１点。最多得点の分類が複数ある場合、６問目から１問目へさかのぼり、同点の分類で最初に現れたものを選びます。同点の他の優しさも結果末尾に表示します。回答修正後は全回答から得点を計算し直します。

６問では４分類すべての同点は数学的に発生しませんが、判定関数は全分類同点にも対応しています。

## 公開

GitHub Pagesで`main`ブランチのルートを公開します。すべて相対パスで指定しているため、`/Virgo/`でも画像・操作が動作します。
